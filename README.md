# SWYNEX Data Analyst Internship – Task 2

## Exploratory Data Analysis (EDA)

This project focuses on analyzing the cleaned Online Retail II dataset from Task 1 to identify sales trends, patterns, important statistics, and anomalies.

### Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

### Analysis Performed
- Dataset overview and summary statistics
- Country-wise sales analysis
- Monthly sales trends
- Top-selling products
- Customer analysis
- Daily sales patterns
- Anomaly detection for quantities and prices

### Key Outcomes
The analysis uses statistical summaries and visualizations to understand retail sales performance, identify trends, and detect unusual records.

### Dataset
The cleaned dataset from Task 1 was used for this analysis.
