# SWYNEX Task 2 – Exploratory Data Analysis (EDA)

## Project Overview

This project was completed as part of the SWYNEX Technologies Data Analyst Internship.

The objective of this task was to explore the cleaned Online Retail II dataset from Task 1 and analyze sales trends, product performance, and country-wise sales using Microsoft Excel.

## Dataset

**Dataset:** Online Retail II  
**Data Used:** Year 2009–2010

The dataset contains online retail transaction information such as invoice numbers, stock codes, product descriptions, quantities, invoice dates, prices, customer IDs, and countries.

## Tool Used

- Microsoft Excel

## Analysis Performed

The following analyses were performed:

1. Identified the top 10 countries by sales.
2. Analyzed the top 10 products by sales.
3. Explored monthly sales trends for 2009–2010.
4. Compared country-wise quantity and sales.
5. Analyzed monthly quantity trends.

## Key Outcomes

- Compared sales performance across countries and products.
- Explored monthly sales and quantity patterns.
- Created five charts to visualize the analysis.
- Identified patterns in retail sales performance.
