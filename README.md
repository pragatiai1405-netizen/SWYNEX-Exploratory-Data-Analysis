# SWYNEX Data Analyst Internship – Task 2

## Exploratory Data Analysis (EDA)

This project focuses on analyzing the cleaned Online Retail II dataset from Task 1 to identify sales trends, patterns, key insights, and unusual records.

### Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Microsoft Excel

### Analysis Performed
- Dataset overview and summary statistics
- Country-wise sales analysis
- Monthly sales trends
- Top-selling products
- Customer analysis
- Daily sales patterns
- Anomaly detection for quantities and prices
- Data visualization to identify sales patterns

### Key Outcomes
The analysis uses statistical summaries and visualizations to explore retail sales performance, understand sales trends, compare countries and products, and identify unusual records.
